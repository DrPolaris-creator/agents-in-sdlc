通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代完成变更规划、代码编写、行为测试、拉取请求审查以及智能体协作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家以开发者为主题、为棋盘游戏提供众筹服务的虚构公司。团队的待办事项已记录为 GitHub 议题，可以直接开始处理，其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进。

## 选择工作环境

无论使用哪种开发环境，都可以借助 GitHub Copilot 工作。选择适合自己的环境；每个工作坊都有独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright 模型上下文协议 (MCP)、Agent Merge 及实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进展，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 代理模式、MCP 服务器和自定义智能体完成开发，无需离开编辑器。
